## 6. Anti-Ghost Verification

Every E2E test MUST verify `_call_counter > 0` for all new modules:

```python
def test_anti_ghost_all_modules():
    """Verify: All V4.4.3 modules activated during dispatch."""
    result = disp.dispatch("test task")
    # ScratchpadHistoryStore
    assert ScratchpadHistoryStore._call_counter > 0
    # AgentIdentity
    assert AgentIdentity._call_counter > 0
    # (V4.4.4) WorkflowTrace
    # (V4.5.0) SkillProvider
```

**CI Integration**: `scripts/check_module_activation.py` extended with new module list. Runs in CI lint job. Fails if any module `_call_counter == 0` after sample dispatch.
