## 1. Test Strategy

### 1.1 Four-Layer Test Pyramid

| Layer | Coverage | Target Share | Estimated Count |
|-------|----------|--------------|-----------------|
| **Unit** | Per-module data models, enums, pure logic | ~60% | ~70 |
| **Contract** | Module ↔ consumer interface contracts (e.g. `RiskRegister` ↔ `UnifiedGateEngine`) | ≥5% | ~10 |
| **Integration** | Cross-module flows (e.g. dispatch → hook → module → report) | ≥15% | ~20 |
| **E2E (xfail TDD)** | Full `dispatch()` increments counters; report sections render; gates fire | ~15% | 10-15 xfail skeletons + xpass targets |
| **Red Team** | Anti-ghost bypass, secret leakage, graceful degradation | included in Integration | ~5 |
| **Total new tests** | | | ~115-120 |

### 1.2 Iron Rules (DevSquad Tester)

- **Iron Rule 1** — Document-first, no guessing APIs: Read source before writing tests.
- **Iron Rule 2** — Failed reports, not loosened assertions: When a test fails, analyze root cause; do not relax thresholds.
- **Iron Rule 3** — Dimension completeness: Happy ≥50% / Error ≥15% / Boundary ≥10% / Performance ≥5% / Config ≥5% / Integration ≥10% / Security ≥5%.

### 1.3 xfail TDD Discipline (V4.3.3 Skeleton)

V4.3.3 ships the E2E skeletons as `@pytest.mark.xfail(reason="V4.4.0 not yet implemented")`. V4.4.0 turns each xfail into xpass by implementing the module. An xfail that unexpectedly passes (XPASS) before V4.4.0 implementation is a test-quality bug.

### 3.1 xfail Skeleton Template

```python
# tests/e2e/test_v440_risk_register.py
import pytest
from scripts.collaboration.dispatcher import MultiAgentDispatcher

@pytest.mark.xfail(reason="V4.4.0 P0-1 Risk Register not yet implemented", strict=True)
def test_e2e_risk_register_assess_after_dispatch():
    """US-R1: A full dispatch() must call RiskRegister.assess() with 7-role votes."""
    disp = MultiAgentDispatcher()
    result = disp.dispatch("Design a payment gateway")
    # After consensus, the dispatch hook should have called assess()
    from scripts.collaboration.risk_register import RiskRegister
    # The register instance is attached to the dispatcher or available via a hook
    register = getattr(disp, "_risk_register", None) or RiskRegister()
    assert register._call_counter > 0, "RiskRegister was never called during dispatch"
    # The report must contain the Risk Management section
    assert "## Risk Management" in result.to_markdown()
    disp.shutdown()
```
