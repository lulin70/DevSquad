## 2. Wave 1 设计 — `_call_counter` 全 `_er` 化

### 2.1 命名约定 (V4.5.3 lesson #4)

**目标**: 100% 闭环 V4.5.3 命名前缀约定

```python
# 旧 (V4.5.4 风格)
_call_counter: dict = {}
def _inc_call_counter(name: str): ...
def get_call_counter(): return _call_counter

# 新 (V4.5.6 风格 — 与 V4.5.6 module_fiber + coeffect 一致)
_call_counter_er: dict = {}
def _inc_call_counter_er(name: str): ...
def get_call_counter_er(): return _call_counter_er
```

### 2.2 替换范围 (74 文件 / 422 行)

按风险分批：

| 批次 | 文件数 | 风险 | 涉及模块 |
|------|--------|------|----------|
| B1.1 | 30 | 低 | dispatcher / report_formatter / file_bundler / dispatch_hooks / approval_gate |
| B1.2 | 25 | 中 | viewpoint_registry / gap_analyzer / error_budget_tracker / quality_calibration_gate / perf_baseline / order_chain_detector |
| B1.3 | 19 | 高 | scratchpad_history_store / gitlab_connector / dependency_hallucination_checker / dora_metrics_collector / agent_identity / task_scale_gate / role_specific_mock_backend / connector_framework / backend_config / skill_provider_builtin / models_dispatch |

### 2.3 替换策略

每批次：
1. `grep -rln "_call_counter[^_]" scripts/ tests/ | head -30` 列出待替换
2. 对每个文件:
   - `sed -i '' 's/_call_counter[^_a-zA-Z]/_call_counter_er/g'` (避免误改 `_call_counter_` 已有 _er 后缀)
   - `sed -i '' 's/get_call_counter/get_call_counter_er/g'`
3. 跑 ruff + 单元测试 + check_module_activation.py
4. 如果绿，git commit；红则 revert

### 2.4 反查 (强)

```bash
# 必须 0 输出
grep -rn "_call_counter[^_a-zA-Z]" scripts/ tests/ | grep -v __pycache__ | grep -v _call_counter_er
```

### 3.2 修复模式

**anti-magic-number** (魔法值 0.95 / 100 / 16x16):
```python
# 旧
assert success_rate > 0.95
assert response_time < 100

# 新
_SUCCESS_RATE_THRESHOLD = 0.95
_RESPONSE_TIME_MS = 100
assert success_rate > _SUCCESS_RATE_THRESHOLD
assert response_time < _RESPONSE_TIME_MS
```

**anti-loose-assert** (assertTrue 替代精确断言):
```python
# 旧
self.assertTrue(response.status_code == 200)
self.assertTrue("error" not in result)

# 新
self.assertEqual(response.status_code, 200)
self.assertNotIn("error", result)
```

## ⚠️ Honest Disclosure (V4.5.6 G6 complete)

DevSQuad V4.5.6 诚实标注协议行为 (对齐 weiransoft/TraeMultiAgentSkill v2.8.4 §G6):

1. **提示词层 AI 由宿主 LLM 完成**:
   - 在 TRAE IDE 内嵌 dispatch 时，宿主 LLM (Claude / GPT-4) 实际处理 7-role 共识

4. **TRAE IDE 外调用 dispatcher**:
   - B-path timeout 600s → FUSE 跳 B → 强制降级 A → 无 API key → C mock
   - 这是 TRAE IDE 设计本身决定，非 DevSquad bug

5. **真实 LLM 路径**:
   - 需要 DevSQuad IDE 内嵌 dispatch (run_mcp 调用)
   - 或显式 OPENAI_API_KEY / ANTHROPIC_API_KEY / MOKA_API_KEY 环境变量

详见 [V4.5.6_DESIGN.md §6](file:///Users/lin/trae_projects/DevSQuad/docs/planning/V4.5.6_DESIGN.md) 与 [V4.5.6_PRD §G6](file:///Users/lin/trae_projects/DevSQuad/docs/prd/V4.5.6_HOST_BRIDGE_TRANSACTION_PRD.md)。
