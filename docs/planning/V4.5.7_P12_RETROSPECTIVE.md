## 5. Lessons Learned (L-V457)

1. **L-V457-001 (Skill vs IDE 边界)**: HostLLMBridge 4 文件协议已 100% 实现；
   异步执行完全是 Skill 侧可控的，不受宿主 LLM 影响。
2. **L-V457-002 (sync bridge 异常语义)**: `resolve()` 检测 running loop 后必须直接
   raise informative error——最初的 try/except 结构把自定义 RuntimeError 自己吞掉，
   然后在 `asyncio.run()` 里以更混乱的 nested-loop 消息崩溃。教训：catch 自己
   raise 的异常来区分路径时，必须让目标路径真的走到正确分支。
3. **L-V457-003 (per-call FSM)**: 实例级 FSM 在并发 re-entry 下必然竞态
   ("Invalid FSM transition")。改为局部变量承载 per-call 状态、实例状态仅作
   诊断，一举消除。
4. **L-V457-004 (CLI 表格行解析)**: 测试解析 Markdown 表格数据行应用特征前缀
   (`"| \`R-"`)，不能用 `startswith("| ")` 再切片 — 分隔行 `|---|` 不匹配
   前缀导致索引静默偏移（本次 2 个测试假失败同根因）。
5. **L-V457-005 (E2E 真实用户模拟)**: 用户规则 "发布前必须模拟真实用户使用" —
   两个 Wave 各带 E2E 用户旅程（7-role 并行调度/失败隔离/超时切断/取消恢复；
   add→list→show→export→clear CLI 全流程 + typo 干净报错），在 P5 而非发布后补。
