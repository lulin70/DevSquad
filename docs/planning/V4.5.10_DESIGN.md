## 2. 组件变更

### 2.1 `scripts/collaboration/host_llm_bridge_v2.py`（重写硬化）

- `create_request()`：request JSON 不再内嵌 `prompt`，仅含 `prompt_file` 指针；prompt 超限在写任何文件前抛错（不留半成品）；marker 最后发布
- `read_marker()`：严格 schema（恰好 7 字段 + 类型 + request_id 合法 + 路径在版本目录内）；任何违规返回 None（fail-closed，不处理）；v1 格式 marker 一律拒绝
- `wait_for_response()`/`read_request()`：O_NOFOLLOW + regular-file + 大小上限的安全读取；JSON 部分写重试保留
- `write_response()`：v2 `timestamp` 字段（非 v1 `completed_at`）；版本限定 marker 清理
- 删除 `_migrate_legacy_marker_v1`（v2 初始化不触碰 v1 文件）

### 2.2 `scripts/collaboration/host_llm_bridge.py`

- v1 默认目录改为 `logs/host_llm_bridge/v1`（隔离，marker 文件名不变）
- 新增 `HostBridgeBackendV2(HostBridgeBackend)`：仅替换 `self.bridge = HostLLMBridgeV2`，完整继承 platform detection / fuse / SUBAGENT_TYPE_MAP / generate 语义

### 2.3 `scripts/collaboration/llm_backend.py`（G-α 生产接线）

- 新增 `_resolve_host_bridge_version()` + `_build_host_bridge_backend()`
- `host` / `auto` B 路径 / `auto-fallback` B 候选 → 按解析版本构建（默认 v2）
- 新增显式类型 `host-v1` / `host-v2`；`trae` passthrough 保持不变
- 修复 `host` 显式路径未传 `timeout_seconds` 的缺陷

### 2.4 CLI `--async`（P2-2 落地）

- `scripts/cli.py`：互斥参数组 `--async` / `--no-async`（dest=`use_async`，三态 None/True/False）
- `scripts/cli_dispatch.py`：`_resolve_use_async()` 优先级 = 显式 flag > `DEVSQUAD_USE_ASYNC` > 同步；`cmd_dispatch` 在 async 分支 `asyncio.run(disp.async_dispatch(...))`
- 缺陷修复：`dispatcher_mixins._execute_async_workers` 在 `llm_backend is None`（mock 模式）时以 "mock" 名解析，并把 `ValueError` 纳入降级捕获——修复 CLI async 在 mock 模式必崩的真实缺陷

### 2.5 anti-ghost

`check_module_activation.py` 新增 `HostBridgeV2Wiring_V4510.1`：真实执行 `create_backend("host")` 并断言实例类型为 `HostBridgeBackendV2`（wiring 层门禁，非存在性检查）。

## 4. 已知行为变化（ Breaking / Notice ）

1. `create_backend("host"/"auto"/"auto-fallback")` 默认返回 v2 adapter；需要 v1 的使用方设置 `DEVSQUAD_HOST_BRIDGE_VERSION=v1` 或 `DEVSQUAD_V455_DISABLE_HOST_BRIDGE_V2=1`
2. v1 默认目录从 `logs/host_llm_bridge/` 迁移到 `logs/host_llm_bridge/v1/`（旧目录文件不迁移、不删除）
3. v2 request JSON 不再内嵌 prompt（上游 v2.8.4 监听方按 `prompt_file` 读取）
4. v2 reader 拒绝 v1 格式 marker（fail-closed）
5. CLI 新增 `--async` / `--no-async`
