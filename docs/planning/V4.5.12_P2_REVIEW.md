- **命名澄清前置**：PRD §0 显式区分"上游 weiransoft v2.8.4 协议参考"与"本地 TRAE IDE 3.3.95 联调对象"，避免版本号混淆（V4.5.10 PRD §1.1 G-α 隐含歧义已修复）。

- **`--severity` 直接删除的边界明确**：删除前先 grep 全仓库 `severity` 引用，AC-SE-5 集成测试断言 API 路由 0 修改通过；AC-SE-3 显式验证 argparse 拒绝 `--severity` 退出码 2。
- **TRAE IDE 联调证据归档**：AC-LA-9 把 5 trace 写入 `docs/e2e_evidence/V4.5.12_trae_ide_real/`，避免"日志即证明"的非正式记录。

### 2.3 决议

## 4. 安全评审（8.6）

### 4.1 强项

- **真实联调新增 TOCTOU 风险已识别**：AC-LA-1 ~ AC-LA-7 把 V4.5.10 PRD §5 R-path（symlink/TOCTOU/越界）带入真实联调场景；AC-LA-7 显式验证跨版本隔离。
- **`--severity` 删除不破坏权限路径**：R-SE 风险登记 + AC-SE-5 集成测试断言 `scripts/api/routes/dispatch.py` 0 修改通过；AC-SE-7 文档扫描保证迁移路径完整。
- **stats 计数器不暴露敏感信息**：`RiskStoreStats` 仅暴露聚合数字（容量/并发数/跨主机信号/慢查询计数），不含 risk 内容、register_id、user_id。
- **TRAE IDE 端日志脱敏**：AC-LA-9 显式要求"脱敏 API Key 等敏感字段"后才归档。

### 4.2 风险点（已含缓解）

| ID | 风险 | 缓解 |
|---|---|---|
| SEC-1 | `cmd_risks_stats --format json` 可能被脚本批量读取并外发（容量信息泄露） | 不视为机密：register 容量、并发计数、慢查询数本身即为运维可观测性数据；CHANGELOG V4.5.12 显式标注为"运维信号" |
| SEC-2 | TRAE IDE 真实联调 trace 5 > 512KB prompt 失败可能误触发 V4.5.10 资源上限 fail-closed | V4.5.10 PRD §5 R-resource 已确认 fail-closed 行为；trace 5 是预期失败场景 |
| SEC-3 | `--severity` 直接删除未给 deprecation 周期 | 用户决策 §0 决策 3 明确"直接删除（Breaking）"；CHANGELOG + README×3 迁移指南覆盖 |

### 4.3 决议

✅ **安全通过**（8.6/10）。3 项风险点全部含缓解；无安全阻塞。
