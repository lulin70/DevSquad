## 2. 教训（Lessons Learned）

- **L-V4512-001（版本号全量替换需人工复核描述段）**: 批量 `4.5.11→4.5.12` 替换后，CLAUDE.md/SKILL.md 的 "V4.5.11 adds bridge log retention..." 描述段被错误改成 "V4.5.12 adds..."——版本描述段必须人工改写而非机械替换，否则前代能力会被错误归属。
- **L-V4512-002（Breaking 删除先 grep 再改 argparse 再迁测试）**: `--severity` 删除按"先改 `_filter_risks` → 再删 argparse 注册 → 再迁 4 份测试 + anti-ghost 脚本 + E2E 旅程"顺序执行，未出现 V4.5.11 L-V4511-004 的 ImportError 雪崩；教训复用成功。
- **L-V4512-003（CLI 输出版本字段也是契约）**: `devsquad metrics` JSON `version` 字段从 V4.5.2 → V4.5.12 触发 2 处测试失败——扩展 L-V4511-006：不只输出行/字段结构是契约，版本标识字段也是契约，变更必须同步测试并在 CHANGELOG 说明。
- **L-V4512-004（事务提交路径与 save 路径要同步埋点）**: stats 初版只在 `save()` 记写，`transaction()` commit 走 `_atomic_write` 直写路径漏埋——单元测试 `test_transaction_path_updates_window` 立即抓出。新计数器必须在所有写入路径等价埋点。
- **L-V4512-005（人工采集证据用模板框架先行）**: TRAE IDE 真实联调无法 CI 化；以"trace 模板 + 采集方法 + 勾选清单"入库存档，将外部依赖型 AC 转化为可审计的框架性交付，避免"证据永远没有文件"。
- **L-V4512-006（pytest 子进程 E2E 的模块/脚本双入口）**: `-m scripts.cli` 不可用（package 无 `__main__`），`python3 scripts/cli.py` 与 `-m scripts.cli_risks` 混用导致 3 处失败——E2E helper 必须显式区分 module 型与 script 型入口。
