### 2.2 脚本设计：scripts/generate_dogfooding_report.py

- 风格：argparse + `main()`（先例一致）；**目标 ≤ 300 行**（size gate 800 上限余量；P0 教训 1——push 前本地跑 `python scripts/check_dispatcher_size.py --max-lines 800 --baseline`）。
- CLI：`--output`（默认 `docs/analysis/dogfooding_report_<YYYY-QN>.md`）；`--skip-slow`（跳过 bandit，供快速迭代）；pip-audit 不设默认执行（网络/时长），报告中该项标注"采集于 CI security job + 附复现命令"，仅 `--with-pip-audit` 开关触发本地执行。
- 采集器：每指标一个函数，subprocess 跑**真实命令**并解析输出 → `MetricRecord(name, value, unit, command, exit_code, timestamp)`。
- **数字纪律（TD-074 教训，硬约束）**：所有数字必须来自本次运行真实输出；解析失败或命令非零 → 该指标显式标 `unavailable`（附原因），禁止任何手写/估算数字。
- 报告结构：① 头部（生成时间、git SHA、生成命令原样）② 指标总表（指标 | 值 | 状态）③ 每指标详情块：值 + **复现命令原样** + 本次采集输出摘录 ④ 附录：CI 门禁对照（本地命令 ↔ CI 调用点）。
- 首期季度报告：生成 `docs/analysis/2026-Q4_dogfooding_report.md` 并入库（生成后人工 commit，报告头部含"由脚本生成，勿手改"声明）。

### 3.2 文档设计：docs/integrations/MCP.md（新建，独立完整）

章节结构：

1. **适用对象与前置**：Cursor / Claude Desktop / TRAE / OpenClaw 等任意 MCP 客户端；Python ≥ 3.10。
2. **安装**：PyPI 形态 `pip install devsquad[mcp]`；仓库形态 `pip install mcp`。两种形态均给出。
3. **连接配置（stdio，默认）**：通用 MCP 客户端配置 JSON 样例（`command: python3, args: ["-m", "scripts.mcp_server"]`），附 Cursor 与 Claude Desktop 两份具体样例；SSE 远程形态（`--port`，默认绑定 127.0.0.1，公网暴露安全注意）。
4. **工具清单表**：9 工具 × 参数 × 权限等级（READ_ONLY/WRITE/ADMIN）× RBAC 附加校验 × 用途一句话。
5. **RBAC 与 fail-closed 行为（PRD 要求写明）**：角色等级模型（`MCP_ROLE_LEVELS`）；拒绝四情形（无身份/未知角色/未知工具/等级不足）逐条列出；`_RBAC_GUARDED_TOOLS`（dispatch/quick）附加校验；示例：低权限角色调用 `multiagent_dispatch` → 收到的 JSON 拒绝响应样例。
6. **验证连接**：客户端 `tools/list` 期望输出（9 工具）；最小验证调用 `multiagent_roles`（READ_ONLY，零 key）。
7. **key 边界（诚实声明）**：零 key 可用工具面（roles/status/analyze/codegraph 只读族）；真实 LLM 产出需 provider key（dispatch/quick 走真实后端时）。
