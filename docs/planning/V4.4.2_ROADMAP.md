## 6. 版本编号规则约束

按用户决策"版本号补丁只能动第三位 patch"：

- **V4.4.2**（当前）: 文档一致性 hotfix 内嵌
- **V4.4.3**（planned patch）: 文档同步自动化门禁
- **V4.4.4**（planned patch）: 目录清理 + Dashboard 浏览器级 E2E
- **V4.5.0**（planned minor）: 性能基准 + CI 性能门禁 + mutation testing
- **V5.0.0+**（planned major）: Kanban / ITSM / 真实 LLM E2E / 多语言扩展 / 插件市场

**SemVer 合规**:
- PATCH（V4.4.x）: 向后兼容的 bug fix + 文档修正 + 工具链改进
- MINOR（V4.5.0）: 向后兼容的新功能（性能门禁阻塞化、mutation testing）
- MAJOR（V5.0.0）: 不兼容变更或重大新特性（Kanban/ITSM/插件市场生态化）
