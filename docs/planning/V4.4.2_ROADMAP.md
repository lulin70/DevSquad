## 3. V4.5.1 — OpenWorker 启发 + 性能基线（planned patch）

**目标**: 从"分析和建议"进化为"分析和执行"。引入连接器框架让 7 角色团队能操作外部系统，搭配用户级审批门禁保证安全，产出形态从"报告"升级为"可交付物"。

**灵感来源**: [andrewyng/openworker](https://github.com/andrewyng/openworker) — "Finished work, not just chat"

### 3.1 OpenWorker 启发特性（3 项）

| ID | 项目 | 优先级 | 说明 |
|----|------|--------|------|
| V451-1 | **Approval Gate**（用户级审批） | P0 | dispatch pipeline 增加可选 `approval_callback`，Worker 执行外部操作（写文件/创建 PR/发送消息）前需用户确认。无人值守时排队到 inbox。安全刚需，连接器框架的前置依赖 |
| V451-2 | **Connector Framework**（连接器框架，GitHub 先行） | P0 | 类似 SkillProvider，定义 `Connector` Protocol 接口。V4.5.1 先实现 GitHubConnector（创建 PR 评论、issue 状态更新、PR 审查提交）。后续迭代加 Jira/Slack |
| V451-3 | **Finished Work Artifacts**（可交付物） | P1 | DispatchResult 新增 `artifacts: List[Artifact]` 字段。Worker 可选择性产出实际工件：Developer → 代码补丁（diff）、Tester → 测试用例文件（.py）、PM → PRD 文档（.md）、Architect → 架构图（mermaid）。命名规则：`artifacts/{session_id}/{role}/{filename}` |

### 3.2 V4.5.0 遗留项（原 V4.5.0 计划未完成项）

| ID | 项目 | 优先级 | 说明 |
|----|------|--------|------|
| V451-4 | 性能基线 snapshot（P95/P99/CPU/memory） | P1 | 建立 V4.5.1 性能基线，为后续性能门禁提供参照 |
| V451-5 | CI performance job 阻塞化（`|| true` → 阻断） | P2 | 性能回归 > 10% 阻断 PR 合并 |
| V451-6 | mutation testing 试点（mutmut，仅核心模块） | P2 | dispatcher/coordinator/consensus 三个核心模块试点 |

### 3.3 质量保障

| ID | 项目 | 优先级 | 说明 |
|----|------|--------|------|
| V451-7 | Dashboard 浏览器级 E2E 实跑 | P1 | 用户规则 3："发布前一定要做模拟真实用户使用的测试" |
| V451-8 | REST API 端到端用户旅程 E2E 实跑 | P1 | 注册→登录→dispatch→查看历史完整链路 |
| V451-9 | Connector Framework 反幽灵 E2E | P0 | 确保连接器真正被 dispatch 调用，不是幽灵功能 |

### 3.4 出口条件

- Approval Gate + GitHub Connector + Artifacts 3 项功能集成到 dispatch pipeline
- 反幽灵验证：3 个新模块 `_call_counter > 0`
- Dashboard + REST API E2E 实跑 PASS
- 性能基线建立

### 3.5 设计约束（ai-quality-control 审核）

| 约束 | 说明 |
|------|------|
| Connector 仅 V4.5.1 仅实现 GitHub | 不贪多，Jira/Slack 延后 |
| Approval Gate 默认关闭 | `approval_callback=None` 时行为与 V4.5.0 一致，向后兼容 |
| Artifacts 可选 | Worker 不产出 artifact 时 `artifacts=[]`，不影响现有报告 |
| 拒绝 aisuite 替代 LLMBackend | 已有成熟方案，不过度设计 |
| 拒绝桌面应用/语音输入 | 不是 DevSquad 核心价值 |

## 6. 风险与依赖

| 风险 | 影响 | 缓解 |
|------|------|------|
| Connector 需 GitHub API token | V451-2 延期 | 支持 API token + OAuth 两种模式 |
| Approval Gate 阻塞 dispatch | 用户体验下降 | 默认关闭，仅显式开启时生效；无人值守排队到 inbox |
| Artifacts 文件路径冲突 | 文件覆盖 | `artifacts/{session_id}/{role}/{filename}` 命名规则 |
| Dashboard E2E 需 Playwright | V451-7 延期 | 已有测试文件，仅需实跑验证 |
| mutation testing 10-50x 慢 | CI 时间膨胀 | 仅核心模块试点，不进 CI 主路径 |
| 真实 LLM E2E 需 API key | V500-5 延期 | CI secrets + 仅 release tag 触发 |
