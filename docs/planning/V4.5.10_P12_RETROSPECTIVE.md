## 4. 教训（Lessons Learned）

- **L-V4510-001（安全评审前置价值）**: 初审安全 5.5/10 列出的 8 项实现级阻塞（共享 marker、无 symlink 校验、无权限、无资源上限等）全部转化为 PRD AC，复审一次性通过——评审发现问题不是负担，是清单
- **L-V4510-002（严格 schema 拒绝协议漂移）**: marker 校验必须拒绝多字段（含 `protocol_version`），否则上游后续加字段会静默进入解析路径
- **L-V4510-003（spawn pickling 陷阱）**: multiprocessing spawn 模式不能 pickle 本地闭包 target；改用 `subprocess.Popen([python, "-m", module, ...])` 更符合"真实子进程"语义
- **L-V4510-004（全量回归与版本同步并发）**: 版本同步期间启动的全量回归会产生时序性 failed（半旧半新工作树）。顺序必须是：代码 → 全量回归 → 版本同步 → 一致性检查 → 补跑受影响测试
- **L-V4510-005（async mock 缺陷由 E2E 暴露）**: `DEVSQUAD_USE_ASYNC=1` CLI 路径在 mock 模式必崩（NoneType backend），此前从未被 E2E 覆盖——env-async 旅程补进 CLI journey 后立即暴露
- **L-V4510-006（环境复现 L-V458-001）**: 前台长命令仍会被 sandbox 挂起（状态 T），pytest 一律 nohup 后台 + 轮询日志
