🚀 Quick Start Commands:

   # First output — the demo (mock backend, zero key):
   devsquad demo

   # Then dispatch your own task (auto-match roles):
   devsquad dispatch -t "your task description"

   # To switch to real AI later, set the key and re-select:
   devsquad backend set openai

   # Use lifecycle commands
   devsquad spec -t "user authentication"
   devsquad build -t "implement login API"
