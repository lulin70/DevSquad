### 2. 自动依赖检测 ✅

**创建**: tests/conftest.py

**功能**:
- 自动检测哪些可选依赖已安装
- 为缺失依赖的测试添加skip标记
- 提供清晰的跳过原因

**代码逻辑**:
```python
def pytest_collection_modifyitems(config, items):
    """Automatically skip tests requiring unavailable dependencies."""
    # Check available dependencies
    optional_deps = {
        "pydantic": _check_import("pydantic"),
        "fastapi": _check_import("fastapi"),
        # ... more checks
    }
    
    # Skip tests with missing deps
    for item in items:
        if "requires_api" in item.keywords:
            if pydantic/fastapi not available:
                item.add_marker(skip("Missing: pydantic, fastapi"))
```
