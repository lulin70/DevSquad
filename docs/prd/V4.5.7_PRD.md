## 2. Goals

### Wave 1 — CoeffectResolver 全异步化 (P0)

**问题**: `CoeffectResolver.resolve()` (V4.5.4 引入) 用 `ThreadPoolExecutor`
阻塞线程 + `threading.Lock`。Worker 函数是同步的,无法与 dispatcher 的
`asyncio.gather` 协调。GPU/网络并发受限。

**目标**:
- `CoeffectResolver` 改用 `asyncio.Lock` + `asyncio.Semaphore` 替换 `threading.Lock` + `ThreadPoolExecutor`
- 公开 `aresolve(coeffect_request) -> Awaitable[CoeffectResult]`
- 保留 `resolve()` 同步入口（向后兼容）,内部用 `asyncio.run()` 桥接
- 6 状态 FSM 不变 (PENDING/READY/RUNNING/COMPLETED/FAILED/CANCELLED)
- Kahn 拓扑算法保持同步实现,但**外部包装**异步

**验收**:
- `tests/e2e/test_coeffect_async_pipeline.py` 验证与 dispatcher 协同时序正确
- `tests/unit/test_async_coeffect_resolver.py` 40+ 测试 (race/deadlock/cancellation)
- `check_module_activation.py` 包含 `async_coeffect_resolver` 反-ghost 计数
- `check_test_quality.py` 0 MAJOR

**范围**: 1 新模块 `scripts/collaboration/async_coeffect_resolver.py` (~280 行)
+ 40 测试 (~500 行)

### Wave 2 — Risk Register UX CLI (P1)

**问题**: V4.5.4 `RiskRegister` 是 Python API only。用户必须写代码才能
查询风险。CLI 缺失。

**目标**:
- 新增 `scripts/cli_risks.py` 注册到 `scripts/cli.py` 顶层
- 子命令: `list` / `show <id>` / `clear` / `export`
- 输出格式: Markdown 表格 (LLM 友好,供 7-Role consensus 消费) + JSON (供脚本消费)
- 集成 `ApprovalGate` — `clear` 子命令需要人工审批 (防误操作)
- 参考 V4.5.2 `cli_doctor.py` 注册模式

**验收**:
- `python3 scripts/cli.py risks list` 输出当前所有 risks (Markdown 表格)
- `python3 scripts/cli.py risks show <risk_id>` 显示 risk 详情
- `python3 scripts/cli.py risks clear --require-approval` 触发 ApprovalGate
- `python3 scripts/cli.py risks export > risks.json` 输出 JSON
- `tests/integration/test_risk_register_cli.py` 20+ 测试

**范围**: 1 新 CLI `scripts/cli_risks.py` (~150 行) + 20 测试 (~250 行)

## 5. Risk Register

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| **R1**: asyncio.Lock nested acquire deadlock | Medium | High | (1) 统一 lock 顺序 (2) lock 加 timeout (3) +20 race condition tests |
| **R2**: asyncio.run() 在已有 event loop 中崩溃 | High | Medium | 检测现有 loop, 用 `loop.run_until_complete()` 而非 `asyncio.run()` |
| **R3**: ApprovalGate 集成破坏 risk_register API 向后兼容 | Low | Medium | 保留 `risk_register.clear()` 旧 API, CLI 单独触发 ApprovalGate |
| **R4**: cli_risks.py 与现有 cli_audit.py 命名冲突 | Low | Low | 子命令命名空间区分 (audit vs risks) |
