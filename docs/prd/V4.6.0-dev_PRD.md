## 6. Honest Disclosure (G6)

- **perf baseline re-measurement is local, single-process**, not
  authoritative for CI. The CI thresholds in
  `tests/test_performance_benchmarks.py` (2 s creation / 50 MB peak)
  are intentionally relaxed (100× above the measured baseline) to
  accommodate noisy shared CI runners. Do not interpret the
  V4.6.0-dev baseline as a CI performance gate — it is a developer
  reference for trend-spotting between iterations.
- **Dashboard Login Journey-12 cannot validate a successful login**
  because `config/deployment.yaml` references password hashes via
  `${DEVSQUAD_*_PASSWORD_HASH}` env-var substitution that is not
  applied to the YAML literal (the hash is left as a literal string
  and verify_credentials therefore always returns None in this
  environment). The journey exercises the form-submit path and
  asserts no exception, which is the user-rule-3 contract.
- **3-language README updates are simultaneous mass-edits** — verify
  any future 204+ → 205+ bump propagates consistently with the same
  pattern (regex `r'204\+'`).
