## 2. Scope (in)

### 2.1 C1 — Codecov 幽灵 step 移除

- **现状**: `test.yml` 使用 `codecov-action@v4`，token 行被注释
  （"uncomment after configuring secret"），`fail_ci_if_error: false` →
  上传每次静默失败。README 三语均无 Codecov badge，项目不消费该服务。
- **实际保障已存在**: `--cov-fail-under=70` 门禁 + `coverage-xml-*` artifact 上传。
- **处置**: 删除 Upload coverage step（保留 artifact 上传 step），注释中记录
  "如未来接入 Codecov 服务，先申请 token 配 secret 再恢复该 step"。
- **范围外**: 不申请 Codecov token、不接入 badge。

### 2.2 C2 — type: ignore 16 处审查分类 + 补 reason 注释

- **现状**: 全仓 `# type: ignore` 共 20 处，其中 4 处为 docstring 文字
  （ue_test_framework_base / workflow_engine_base / dispatcher_base /
  prompt_assembler_base），真实 ignore = 16 处。CI mypy 绿证明全部必要
  （`warn_unused_ignores = true` 下冗余 ignore 会报错）。
- **分类**:

| 类别 | 位置 | 数量 | 处置 |
|---|---|---|---|
| 可选依赖 fallback stub | prometheus_metrics.py（Counter/Gauge/Histogram/Info）、skillifier.py、mcp_server.py:140 | 6 | 保留 + 补 reason |
| 动态元编程 | coeffect.py（装饰器动态赋值 `__devsquad_*__` / classmethod 包装 / override） | 8 | 保留 + 补 reason（L-V454-001 模式） |
| 第三方扩展缺 stub | dag_views.py `st.mermaid` | 1 | 保留（已有注释，统一格式） |
| 参数透传 | mcp_server.py:493 `call-arg` | 1 | 保留 + 补 reason |

- **统一格式**: `# type: ignore[code]  # <reason>`，reason 一句话说明为何
  无法用正常类型表达。
- **产出**: 每处 ignore 均有可审计理由；不改运行时行为。
