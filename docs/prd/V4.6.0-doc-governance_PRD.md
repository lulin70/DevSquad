## 2. Scope (in)

### 2.1 Security P0（P1 bandit 门禁 + 修 fail-closed bug）

- **bug fix**: `scripts/check_bandit.py` 在 bandit 返回非零 exit + 空 stdout
  时仍打印 PASS。修复：新增 `_is_scan_clean()` 守护，空 / 非法 JSON 报告
  必 fail closed（exit 1）。
- **compatibility**: `_parse_json_report()` 容忍 bandit 1.9.x 的
  `SEVERITY.HIGH/MEDIUM/LOW` 新 schema 与旧 `HIGH/MEDIUM/LOW` 双 schema。
- **noise reduction**: 加 `-q` 抑制 progress bar；`_summarize()` 读
  `SEVERITY.HIGH` 时回退 `HIGH`，消除误判。
- **threshold 公开化**: 新增 `--max-medium N` 把当前 7 MEDIUM 基线公开为
  CI 阈值（默认仍 fail-on-any-medium）。
- **dev-dep**: `bandit[toml]>=1.7` / `pip-audit>=2.7` / `radon>=6.0` 加入
  `pyproject.toml` `[project.optional-dependencies].dev`。
- **CI 接线**:
  - `.github/workflows/test.yml` security job：替换 raw `bandit -r scripts/`
    为 `check_bandit.py --max-medium 7` + 一个 informational breakdown step。
  - `.github/workflows/release-e2e.yml` final-gate：新增 hard step
    `check_bandit.py --max-medium 7`（HIGH 必为 0）。
- **tests**: `tests/test_check_bandit.py` 新增 13 个用例覆盖 fail-closed /
  scan_clean / summarize / exit codes / bandit-presence / e2e smoke。

### 2.2 Maintainability P0（P2 dispatcher size 门禁）

- **new gate**: `scripts/check_dispatcher_size.py` — 扫 `scripts/` 下所有
  `.py` 的非空 LOC，超 `--max-lines 800` 时 fail。
- **baseline-friendly**: 第一跑用 `--write-baseline` 锁定当前 297 文件的
  LOC 快照（基线文件 16 文件本已 > 800，属历史债）。
- **net-growth only**: 之后每次跑只比对「净增长」—— 新增或扩大的文件
  block release，存量债不阻塞（明确留给后续 refactor PATCH）。
- **baseline 落盘**: `docs/audits/dispatcher_size_baseline.json` 记录
  297 文件 LOC + max_lines + generated_at + version。
- **CI 接线**:
  - `test.yml` lint job：soft step 跑 gate（新增 growth 即 fail）。
  - `release-e2e.yml` final-gate：hard step 跑 gate。
- **tests**: `tests/test_check_dispatcher_size.py` 新增 11 个用例覆盖
  snapshot / pycache 排除 / 空行不计 / baseline 读写 / net-growth 阻断。
- **不拆代码**: 按用户决策 "只加门禁脚本不拆代码" — dispatcher.py 1377 行
  / components.py 1051 行等历史债保留，留待 V4.6.x 后续 PATCH 逐步拆。

## 5. Rollback

If release is blocked, two escape hatches:

1. `--no-fail-on-medium --max-medium 99` (bandit): relaxes MEDIUM gate to
   informational only. HIGH gate remains blocking.
2. Delete `docs/audits/dispatcher_size_baseline.json` and rerun with
   `--write-baseline`: re-locks the current state so CI does not block on
   historical debt.

Neither escape hatch skips HIGH-severity or net-growth checks.
