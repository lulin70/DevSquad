## 8. Honest Disclosure (V4.5.6 G6 Complete)

- **perf baseline is a developer snapshot, not a CI gate.** CI
  thresholds in `tests/test_performance_benchmarks.py` (2 s creation /
  50 MB peak) are intentionally 100× above the measured baseline to
  accommodate noisy shared CI runners. Use the snapshot for
  trend-spotting, not for gating.
- **Dashboard Login Journey-12 cannot validate a successful login**
  because `config/deployment.yaml` references password hashes via
  `${DEVSQUAD_*_PASSWORD_HASH}` env-var substitution that is not
  applied to YAML literals (security-by-design — passwords never
  committed). The journey exercises the form-submit path and asserts
  no exception, which is the user-rule-3 contract.
- **The 3-language README updates are simultaneous mass-edits.**
  Any future 204+ → 205+ bump must propagate through the same 9 files
  (regex `r'204\+'` in any release tooling).
