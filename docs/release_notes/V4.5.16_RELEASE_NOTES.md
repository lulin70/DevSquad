## Closed Hard Risks (4)

1. **`_version_info` 元组对齐** — V4.5.15 之前 `__version_info__ = (4, 5, 11)` 但 `__version__ = "4.5.15"`，依赖元组比较的代码可能误判版本；修复为 `(4, 5, 16)` + `"4.5.16"`。
2. **Helm chart tag 4.5.16** — `helm/devsquad/values.yaml:5` `image.tag` 由 `"4.0.0"` 改为 `"4.5.16"`；`Chart.yaml` `version + appVersion` 由 `4.5.15` 改为 `4.5.16`。运维不再因 default 回退误判。
3. **`scripts/publish_now.sh` 死代码归档** — V3.7.0 死代码 `git mv` 至 `docs/_archive/scripts/`；现由 GitHub Actions `release.yml` 接管。
4. **`test.yml::lint` 加 anti-ghost** — `python scripts/check_module_activation.py` 默认随 `lint` 跑（之前只在 `perf-baseline.yml::perf-mock` nightly 触发）；nightly 漏检风险关闭。

### G. 新工具 `scripts/sync_skill_pack.py`

- **用法**：
  ```bash
  python3 scripts/sync_skill_pack.py              # 默认三层缓存同步
  python3 scripts/sync_skill_pack.py --dry-run    # 预览
  python3 scripts/sync_skill_pack.py --quiet      # 安静模式
  python3 scripts/sync_skill_pack.py --repo-root  # 强制 repo-root whitelist
  ```
- **默认行为**：`SKILL.md` + `skill-manifest.yaml` 顶层白名单；SHA-256 校验；不触碰同级 pack
- **Pack 合约检测**：当 `--source` 含 `tests/` / `scripts/` / `.venv/` / `__pycache__` 等 repo 指示符时，**只同步顶层两个白名单文件**，避免把整个 repo 误同步到 `~/.trae-cn/skills/devsquad`
- **测试**：7 PASS（happy + dry-run + SHA-256 + clean-extra + CLI help）
