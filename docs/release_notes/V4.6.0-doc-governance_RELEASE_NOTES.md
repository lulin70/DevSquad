## 1. Security: Bandit CI Gate

### 1.1 Bug fix: fail-closed on empty stdout

`scripts/check_bandit.py` 之前的版本在 bandit 返回非零 exit + 空 stdout 时
会打印 `PASS: bandit gate (HIGH=0; MEDIUM within tolerance).` (exit 0)。
本 PATCH 修复：

```python
def _is_scan_clean(report: dict) -> bool:
    if not report:
        return False
    return "results" in report and "metrics" in report

# in main():
if not clean:
    print("FAIL: bandit scan did not produce a parseable JSON report. ...",
          file=sys.stderr)
    return 1
```

### 1.2 Compatibility: bandit 1.9.x schema

新增 `_parse_json_report()` 容忍 CLI progress 前缀；`_summarize()` 优先读
`SEVERITY.HIGH/MEDIUM/LOW`，回退 `HIGH/MEDIUM/LOW`，向后兼容旧版。

### 1.3 Threshold 公开化

```bash
# 当前 baseline: 0 HIGH / 7 MEDIUM / 103 LOW
python3 scripts/check_bandit.py --max-medium 7    # release gate
python3 scripts/check_bandit.py --no-fail-on-medium --max-medium 7  # PR soft gate
```

## 2. Maintainability: Dispatcher Size Gate

### 2.1 New gate

`scripts/check_dispatcher_size.py` — 扫 `scripts/` 下所有 `.py`，超过
`--max-lines 800` 时 fail。`__pycache__` / `.hidden` 自动排除，空行不计。

### 2.2 Baseline

`docs/audits/dispatcher_size_baseline.json` 锁定 297 文件 LOC 快照：

| 范围 | 文件数 | 备注 |
|---|---|---|
| 总 LOC 跟踪文件 | 297 | 全部 Python 文件 |
| 已 > 800 LOC | 16 | 历史债，不 block（净增长才 block） |
| Top 1 | 1420 行 | `scripts/qa/deterministic_rule_engine.py` |
| Top 2 | 1223 行 | `scripts/collaboration/dispatcher.py` |

### 2.3 Net-growth-only 策略

```bash
# First run: snapshot
python3 scripts/check_dispatcher_size.py --write-baseline

# Subsequent runs: diff against baseline
python3 scripts/check_dispatcher_size.py --max-lines 800 \
    --baseline docs/audits/dispatcher_size_baseline.json
```

只有净增长（loc > baseline[file]）block release。历史债保留，留
后续 V4.6.x PATCH 逐步拆。

### 2.4 CI 接线
