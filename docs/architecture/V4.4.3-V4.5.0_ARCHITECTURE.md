## 2. V4.4.3 Module Designs

### 2.1 ScratchpadHistoryStore

**File**: `scripts/collaboration/scratchpad_history_store.py` (~150 lines)

**Responsibility**: Cross-session persistent storage for Scratchpad entries with search.

```python
class ScratchpadHistoryStore:
    """SQLite-backed cross-session Scratchpad history.

    Cold/archive store — in-memory Scratchpad remains the hot path.
    Every write() mirrors to SQLite for future search_history() queries.
    """

    _call_counter: int  # anti-ghost

    def __init__(self, db_path: str, retention_days: int = 90): ...

    def write(self, entry: ScratchpadEntry, scratchpad_id: str) -> None:
        """Mirror a Scratchpad entry to persistent storage.
        Applies ContentCache.filter_sensitive_data() before write (Security A2).
        """

    def search_history(
        self, query: str = "", since: datetime | None = None,
        entry_type: EntryType | None = None, role_id: str | None = None,
        limit: int = 50,
    ) -> list[ScratchpadEntry]:
        """Search across all past scratchpad instances."""

    def cleanup_expired(self) -> int:
        """Delete entries older than retention_days. Returns count deleted."""
```

**SQLite Schema**:
```sql
CREATE TABLE IF NOT EXISTS scratchpad_history (
    entry_id TEXT NOT NULL,
    scratchpad_id TEXT NOT NULL,
    worker_id TEXT,
    role_id TEXT,
    entry_type TEXT NOT NULL,
    content TEXT NOT NULL,       -- sensitive-data filtered
    confidence REAL,
    tags TEXT,                   -- JSON array
    created_at TEXT NOT NULL,
    PRIMARY KEY (entry_id, scratchpad_id)
);
CREATE INDEX IF NOT EXISTS idx_history_role ON scratchpad_history(role_id);
CREATE INDEX IF NOT EXISTS idx_history_type ON scratchpad_history(entry_type);
CREATE INDEX IF NOT EXISTS idx_history_time ON scratchpad_history(created_at);
```

**Integration Point**: `Scratchpad.__init__` accepts optional `history_store: ScratchpadHistoryStore`. `Scratchpad.write()` calls `history_store.write()` after in-memory update. Synchronous (Coder review: ~1ms SQLite write acceptable).

**Config** (`.devsquad.yaml`):
```yaml
scratchpad:
  history_enabled: true
  history_db_path: "data/scratchpad_history.db"
  history_retention_days: 90
```

### 2.2 AgentIdentity

**File**: `scripts/collaboration/agent_identity.py` (~80 lines)

**Responsibility**: Deterministic agent identity for cross-session tracking.

```python
@dataclass(frozen=True)
class AgentIdentity:
    """Deterministic agent identity derived from (role, backend, model).

    Same configuration → same agent_id across sessions.
    Enables: "which AI instance made this decision 3 weeks ago?"
    """
    agent_id: str        # e.g. "agent-architect-a1b2c3d4"
    role_id: str         # e.g. "architect"
    backend: str         # e.g. "mock" / "openai" / "anthropic"
    model: str           # e.g. "gpt-4" / "claude-3"

    _call_counter: int   # anti-ghost (class-level)

    @classmethod
    def create(cls, role_id: str, backend: str = "mock", model: str = "mock") -> "AgentIdentity":
        """Create deterministic identity. agent_id = agent-{role}-{sha256[:8]}."""

def derive_agent_id(role_id: str, backend: str, model: str) -> str:
    """Derive deterministic agent_id: 'agent-{role}-{sha256(role:backend:model)[:8]}'."""
```

**Integration Points**:
1. `Worker.__init__`: create `AgentIdentity` from role + backend info
2. `DispatchAuditLogger`: new `agent_id` column (nullable); `log_dispatch_start()` accepts optional `agent_id`
3. `DispatchResult.worker_results`: each result includes `agent_id`

**Backward Compatibility**: `agent_id` column nullable. Existing audit logs without agent_id remain valid. `query_by_agent(agent_id)` returns only entries with matching agent_id.

## 5. Data Flow

### 5.1 V4.4.3 Dispatch with Persistence

```
dispatch(task, roles)
  → Worker.__init__: AgentIdentity.create(role, backend, model) → agent_id
  → Scratchpad.write(entry): mirror to ScratchpadHistoryStore.write()
  → DispatchAuditLogger.log_dispatch_start(user_id, task, roles, agent_ids)
  → ... workers execute ...
  → DispatchAuditLogger.log_dispatch_end(user_id, success, agent_ids)
  → ReportFormatter: render report (with WorkflowTrace if V4.4.4)
```

### 5.2 Cross-Session Search (V4.4.3)

```
User: "What did architect decide last week?"
  → ScratchpadHistoryStore.search_history(query="architect", since=7_days_ago)
  → Returns entries from past scratchpad instances
  → User sees past decisions across sessions
```
